# XFCE dock icons

The three 128 px PNGs are unmodified Crystal Clear icons by Everaldo Coelho
and YellowIcon, released under LGPL 2.1 or later. The collection dates to
2005 and matches the Firefox 1.0–3.0 logo already used in this repository.

- `terminal.png`: [Crystal Clear app konsole](https://commons.wikimedia.org/wiki/File:Crystal_Clear_app_konsole.png)
- `files.png`: [Crystal Clear app file-manager](https://commons.wikimedia.org/wiki/File:Crystal_Clear_app_file-manager.png)
- `applications.png`: [Crystal Clear app demo](https://commons.wikimedia.org/wiki/File:Crystal_Clear_app_demo.png)

Each source page records the author, license, and original file. A copy of the
license is included as `LICENSE.LGPL-2.1`.
